# Ch 9. 가상 메모리 관리
---

### 1. 가상 메모리 관리의 목적 및 비용 모델

- **목적:** 가상 메모리 시스템 성능의 최적화.
- **비용 모델:** **페이지 부재 발생 빈도(Page Fault Rate)**를 최소화하여 Context Switch 및 커널 개입을 줄이는 것이 핵심입니다.
- **하드웨어 구성:** 주소 사상을 돕는 **TLB**, **Reference Bit**(최근 참조 여부), **Update Bit**(데이터 수정 여부) 등이 사용됩니다.

### 2. 소프트웨어 관리 전략 (기본 5요소)

가상 메모리 성능을 조절하기 위해 OS가 사용하는 5가지 주요 전략입니다.

- **Fetch Strategy:** 페이지를 언제 메모리에 올릴 것인가? (Demand Fetch, Anticipatory Fetch) .
- **Placement Strategy:** 페이지를 어디에 배치할 것인가? (Paging에서는 고정 크기라 단순하지만 Segmentation에서는 First-fit 등 필요) .
- **Replacement Strategy:** 메모리가 꽉 찼을 때 어떤 페이지를 내보낼 것인가?.
- **Cleaning Strategy:** 변경된 페이지(Dirty Page)를 언제 Swap Device에 기록할 것인가?.
- **Load Control Strategy:** 시스템 내 프로세스 수를 조절하여 **쓰레싱(Thrashing)**을 방지합니다.

### 3. 고정 할당 기반 교체 알고리즘 (Fixed Allocation)

프로세스에 할당된 프레임 수가 고정된 상태에서 페이지를 교체하는 방식들입니다.

- **MIN (OPT):** 향후 가장 오랫동안 참조되지 않을 페이지를 교체 (이론적 최적).
- **FIFO:** 가장 먼저 들어온 페이지를 먼저 교체.
- **LRU (Least Recently Used):** 가장 오랫동안 사용되지 않은 페이지를 교체.
- **LFU (Least Frequently Used):** 참조 횟수가 가장 적은 페이지를 교체.
- **Clock / Second Chance:** 하드웨어 비트를 이용해 LRU와 유사한 효과를 내는 효율적인 방식들입니다.

### 4. 가변 할당 기반 교체 알고리즘 (Variable Allocation)

프로세스의 필요에 따라 할당 프레임 수를 조절하는 동적인 방식입니다.

- **Working Set (WS) 알고리즘:** 특정 시간 윈도우(Δ) 동안 참조된 페이지 집합을 메모리에 유지하여 성능을 높입니다.
- **Page Fault Frequency (PFF) 알고리즘:** 페이지 부재 간격(IFT)을 측정하여 부재가 잦으면 할당을 늘리고, 드물면 줄입니다.
- **VMIN:** 가변 할당 환경에서의 최적 알고리즘(이론적).

### 5. 기타 고려사항 및 성능 최적화

- **Page Size:** 페이지가 작으면 내부 단편화가 줄지만 테이블이 커지고 I/O 오버헤드가 증가합니다.
- **Program Restructuring:** 프로그램 코드 작성 시 데이터 접근 순서(Locality)를 고려하면 페이지 부재를 크게 줄일 수 있습니다 (예: 2차원 배열의 행/열 참조 순서).
- **TLB Reach:** TLB가 커버할 수 있는 메모리 범위를 의미하며, 이를 넓히는 것이 성능 향상에 중요합니다.
